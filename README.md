# PythonCraft — Интерактивный курс и тренажёр Python 🐍

Автономная веб-платформа для изучения языка программирования Python и онлайн-песочница с исполнением реального кода прямо в браузере.

## 🌟 Возможности

- **Реальный Python 3.12 в браузере**: благодаря движку **Pyodide (WebAssembly)** код выполняется локально на клиенте без необходимости внешних бэкенд-серверов.
- **Интерактивный учебник**: 6 стартовых практических уроков (от `print()` и срезов списков до `list comprehension` и модуля `statistics`).
- **Свободная песочница (Sandbox)**: режим свободной разработки для проверки любых произвольных скриптов и алгоритмов.
- **Интерпретатор & Терминал**:
  - Нумерация строк, отступы (Tab добавляет 4 пробела).
  - Горячая клавиша запуска: `Ctrl + Enter` (или `Cmd + Enter`).
  - Вывод `stdout`, `stderr` и полных трейсов ошибок.
  - Автоматическая валидация решений с начислением XP и салютом из конфетти.
- **Минимализм в тёмных пастельных тонах**: палитра Sage Green `#7EBA94`, Pastel Blue `#7FA7E8`, Peach `#E09F7D` на бархатном темном графите `#0D0F12`.
- **Сохранение прогресса**: весь написанный код и прогресс уроков автоматически сохраняются в `localStorage`.

## 🚀 Как запустить

### Вариант 1 (Быстрый запуск в 1 клик):
Дважды кликните по файлу **`run_site.bat`** — он запустит локальный веб-сервер и автоматически откроет страницу в вашем браузере.

### Вариант 2 (Через терминал):
```bash
py -m http.server 8000
```
Затем откройте в браузере: [http://localhost:8000](http://localhost:8000)

### Вариант 3:
Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Firefox, Opera, Brave).
